# 论文主线独立审稿审查（历史版本）

> 本报告基于早期`epoch17 + F-A1`主方法。当前方法已按Dense256主任务冻结为
> `5A + epoch16 + B2`；创新性风险仍可参考，涉及模型选择和实验缺口的条目应以
> `PROJECT_STATUS.md`及修订后的论文V10为准。

日期：2026-08-15

## 总结判断

当前工作有 ICRA 级别的实验现象，但还没有形成 ICRA 级别的创新论证。

目前最可靠的结论是：

> 在当前五车仿真和冻结 validation 上，可部署时序 Gate 相对于 5A 能够提高 episode-level success 并降低碰撞，但代价是明显增加平均步数。

目前不能成立的结论包括：

- 两个专门化 Actor 优于同等参数量的单 Actor；
- Gate 学会了“何时切换更有利”；
- DAgger 数据聚合提升了闭环性能；
- Gate 已经证明 single-edge 到 multi-edge 的零样本泛化；
- 方法已经在多车数、多地图或动力学变化下泛化。

## 1. 创新性

### 1.1 不能作为创新点的内容

“两个 Actor + 一个 Gate”本身不是新的算法结构。已有工作已经覆盖：

- Options / Option-Critic：策略与 termination 的时序切换；
- APPLI / APPLR：根据环境上下文选择 planner 参数或策略；
- SafeDAgger：学习何时让 expert 接管；
- Learning by Cheating、Asymmetric Actor-Critic：特权 teacher 与局部观测 student；
- Mixture-of-Experts 和 policy routing；
- CADRL 及后续多机器人导航工作：无通信、局部观测下的机器人避碰。

本地相关工作索引见：

[RELATED_WORK.md](/home/jiutian/Local-Critic-Multi-Robot-Navigation-gate/experiments/03_保留专门化/02_论文主线/11_可部署在线Gate研究/RELATED_WORK.md)

### 1.2 可以保留的创新边界

较稳妥的表述是：

> 在无通信、多机器人、局部传感器约束下，将普通导航策略和局部交互策略冻结，通过包含短时历史和候选动作差异的可部署 Gate 进行逐机器人在线路由，并使用特权交互标签和 student rollout 训练。

这属于问题约束、策略角色定义和实验组合上的贡献，不是新的 Gate 学习算法。独立审查给出的主观评分为：

- 算法创新：`2/5`；
- 系统与实验问题价值：`3/5`。

如果没有有效容量对照和更强的 Gate 论据，创新性不足以支撑 ICRA 主贡献。

## 2. 当前已被支持的论据

### 2.1 F-A1 相对 5A 的总体收益

G17 是当前最可靠的结果：

- 120 个冻结场景；
- standard/dense、0-edge/edge-1/multi-edge 分层；
- 两个评测 repeat；
- 相同场景、物理参数和终止条件；
- F-A1 相对 5A：42 场改善、19 场退化；
- McNemar exact `p=0.00444`；
- full success：`0.5958 vs 0.5000`；
- collision：`0.1483 vs 0.1925`。

因此可以写：

> F-A1 在当前完整五车 validation 上相对于 5A 具有总体导航收益。

### 2.2 Dense 场景收益

G18 dense256压力集上：

- 5A full success：`0.2695`；
- F-A1 full success：`0.4023`；
- F-A1 相对 5A 的 McNemar exact `p=4.45e-5`；
- collision 从 `0.3000` 降至 `0.2227`。

可以写：

> F-A1 在高密度场景上的收益方向和总体 validation 一致。

但不能据此写成所有多冲突分层均显著提升。

## 3. 关键严谨性问题

### 3.1 Gate 标签不是切换收益标签

当前主要 teacher 标签是：

```text
最近机器人真值距离 <= 2 m
```

该标签回答的是“附近是否进入交互窗口”，不是：

```text
epoch17 在当前状态下是否比 5A 的长期导航结果更好。
```

所以“Gate 学习何时切换更有利”是过强表述。当前实现严格来说是：

> 用局部时序观测预测一个特权距离切换规则。

论文应改为“privileged rule distillation”或“部署观测下的时序策略路由”。若想声称
Gate 学习切换收益，必须在相同状态上对两个 Actor 做短时 counterfactual rollout，并
用 collision、success、progress 和 timeout 组成预注册收益标签。

### 3.2 容量对照尚未成立

- R2-10k 从单车到五车训练，结果很好，但课程、预算和训练血缘与双 Actor主线不一致；
- R2B-best 的 checkpoint 位于 Actor有效更新前，新增容量没有真正被使用；
- 当前没有一个“训练充分、协议公平、参数匹配”的大 Actor最终对照。

因此不能写：

> 双 Actor + Gate 已经优于同等参数量单 Actor。

当前正在运行的 `g12-r2c-corrected` 是从 R2-10k 继续训练的 cross-protocol continuation，
不是 G19 的成对公平容量对照，完成后不能放入正式容量主表。

### 3.3 DAgger 论据没有得到正面验证

F-B2 是 student rollout 聚合后的 Gate，但：

- G11-F-C：F-A1 `0.710`，F-B2 `0.680`；
- McNemar exact `p=0.6636`；
- F-B2 平均步数 `44.87`，F-A1 `33.41`；
- G18 中 F-B2 仅比 F-A1 高 `0.0117`，`p=0.8126`。

只能写：

> 实现并评估了 DAgger-like 数据聚合消融。

不能写：

> DAgger 提升了 Gate性能。

### 3.4 Multi-edge 统计功效不足

G17 multi-edge只有80个 episodes：

- F-A1：`0.2375`；
- 5A：`0.1750`；
- 改善13场、退化8场；
- `p=0.38331`。

这只能支持正向趋势，不能支持显著提升或零样本泛化。

### 3.5 效率代价显著

G17：

- F-A1平均步数：`31.61`；
- 5A平均步数：`21.63`；
- 增加 `46.2%`。

G18：

- F-A1平均步数：`32.94`；
- 5A平均步数：`17.46`；
- 增加 `88.7%`。

这说明当前 Gate 可能是通过大量调用保守 Actor换取成功率，而不是已经学会精确切换。
效率必须放进论文主表和主讨论。

### 3.6 epoch-17 的选择规则发生过修订

epoch-17 相对 epoch-16 的 full success 方向更好，但平均步数为 `1.159x`，超过原先
`1.10x` 硬门槛，配对检验 `p=0.1421`。之后项目把平均步数从硬约束改为必须报告的
效率代价，再选择 epoch-17。

这一修订已经记录，不能隐藏；epoch-17 应标为基于 exploratory matched validation
选择的当前候选，不能包装成完全预注册确认结果。

## 5. 最小补实验

### P0：固定实验身份

当前 `g12-r2c-corrected` 完成后归档为：

```text
cross-protocol continuation diagnostic
```

不进入正式公平容量主表。

### P1：真正有效的容量对照

必须满足：

1. 单 Actor 从训练早期就使用 `24-1137-855-2`；
2. 与普通 Actor使用相同场景课程、总 agent samples、reward、Critic类型和模型选择规则；
3. Actor确实发生更新；
4. 在 G17 同一120场和相同 repeat 上评测；
5. 同时比较 5A、F-A1、epoch17 always-on 和 2 m rule。

若做不到，应删除“专门化优于参数量增加”和“优于同容量单 Actor”两条主张，只把容量
对照写成局限性。

### P2：修正 Gate 论文表述

低成本方案：将 Gate 定义为“部署观测对特权距离切换规则的时序蒸馏”，删除“学习切换
收益”。

高成本方案：对相同状态分别短时 rollout 5A 和 epoch17，建立预注册的反事实收益标签，
再训练 Gate，才可以声称它学习了切换收益。

### P3：最终统一复测

同一冻结 manifest、seed、顺序和至少3个 repeat，比较：

- 5A；
- epoch16 always-on；
- epoch17 always-on；
- static LiDAR/TTC Gate；
- F-A1；
- F-B2；
- 有效参数匹配单 Actor；
- 2 m privileged rule。

报告逐 repeat效果、scenario-cluster bootstrap 95% CI，并预先指定主要比较。多重比较
需要 Holm 校正，或明确把分层结果定义为探索性分析。

### P4：multi-edge

至少补充200个独立 multi-edge episodes，并分开报告 edge-2 与 edge-3+。如果 Gate训练
使用了 multi-edge 数据，则删除 single-edge 到 multi-edge 零样本泛化主张。

## 最终审稿结论

若以“两个 Actor + Gate 是新算法”为主要贡献投稿，我会给 Weak Reject。

若完成有效容量对照，删除“切换收益”和“零样本泛化”的过强表述，将贡献收窄为：

> 局部观测、多机器人无通信条件下，基于特权交互规则蒸馏、候选动作分歧和时序状态保持的在线策略路由。

再加上统一重复评测和完整效率分析，工作才有机会达到 ICRA 的可审水平。
