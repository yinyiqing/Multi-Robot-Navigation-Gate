# G11-A 已有数据时序 Gate Pilot

状态：`A0 passed / A1 data pending`。日期：`2026-08-04`。

## 目的

先回答两个低成本问题：

1. 两个冻结 Actor 对同一观测的候选动作和动作差是否提供额外 Gate 信息；
2. 在 G0/G1 目标级连续特征上加入短时序是否优于旧逐帧 MLP。

本阶段不回答最终闭环收益，也不训练或修改任何 Actor。

## 数据边界

- 输入：旧 G2-A `pilot_train` 100场与 `pilot_validation` 100场；
- 两个 split 的 scenario ID 互斥；
- sealed test 不读取；
- 旧 positive-edge 包含 multi-edge，只有3个train和2个validation shard属于 corrected
  edge-1。因此 A0 只作表示兼容性诊断，checkpoint 不进入当前方法或拓扑泛化结果。

若 A0 通过，A1 必须重新采集只含导航 train 内部 0-edge 与 corrected full-horizon
edge-1 的互斥 train/validation 数据。

## 报告指标

- frame precision、recall、FPR、F1、average precision；
- standard/weak FPR；
- 正交互事件召回、事件precision、持续区间IoU和进入延迟；
- 预测切换次数。

## 继续条件

A0 只有在以下条件满足时才授权 A1 采集：

1. S0 与旧 G2-A 指标差异可解释且实现审计通过；
2. S1 或 T1 在同一 validation、同一标签和同一阈值约束下明确优于 S0；
3. 增益不是通过显著提高 standard/weak FPR 或切换次数得到。

如果 S1/T1 没有明确增益，停止该表示路线，不采集新 Gazebo 数据。

1. S0精确复现旧Gate，评估链路有效。
2. S1没有稳定增益，关闭“只加Actor动作的单帧Gate”。
3. front/T1没有超过front/S0，不采用前方标签作为最终蒸馏目标。
4. any/T1通过表示准入，授权采集A1的0-edge与corrected edge-1数据。
5. A0旧shard含multi-edge；本轮checkpoint全部保持`diagnostic_only`，不能进入论文主结果。
