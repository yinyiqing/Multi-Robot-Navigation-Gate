# G18 Dense256当前大Actor复测

状态：`complete / audited`。登记日期：`2026-08-15`。

## 目的

在历史dense256完全相同的场景、seed和物理协议上补跑当前流程匹配容量baseline
`R2B-best`和epoch-17 Gate套件，判断当前方法在高密度多冲突压力集上的表现。该实验
只做评测，不更新任何Actor、Gate或阈值，不读取sealed test。

## 固定协议

- manifest：`datasets/fixed_v1/dense/validation.json.gz`；
- manifest SHA-256：`2d1dde389f927b924fa5993c47460bc60bac42aa9506ae3869c3139c9d1264b7`；
- 场景：manifest原始顺序前`256`场；
- 冲突构成：0-edge `8`、1-edge `61`、2-edge `80`、3+-edge `107`；
- seed：`20260810`；固定物理步长`0.001`；
- Actor：`capacity_wide_r2b_5a_recipe_n5_seed20260823_best`；
- Actor SHA-256：`da28dd5820d09845eea07cb68da45a7afd262fe56e8a71f80bf6b5781551523a`。

R2B-best是按5A流程和预算选择出的训练流程输出，但其best位于Actor有效更新前，新增容量
没有被使用。该限制不因本次评测改变；本实验不是“训练充分大Actor”的最终答案。

R2B-best完成后，严格顺序运行：

1. 5A；
2. epoch-17 + F-A1；
3. epoch-17 + F-B2；
4. epoch-17 + old B2直接迁移；
5. epoch-17 + 2m真值距离规则。

old B2直接迁移只作诊断；F-A1和F-B2才是使用epoch-17数据重建的Gate。2m规则是
privileged固定规则，不是严格性能上界。

## 执行与报告

```bash
bash scripts/start_g18_dense256_r2b.sh
bash scripts/start_g18_dense256_gate_suite.sh
```

任务使用全局单Gazebo锁；若G17仍运行，则在后台等待锁，不并发启动仿真。结果必须满足：

- shape为`(256, 17)`；
- scenario ID逐项等于dense validation前256场；
- 终止计数为`256 x 5 = 1280`。

第二个入口会等待第一个入口成功归档，再自动运行后续五组。完成后报告overall和
`0/1/2/3+`分层，并与历史同场epoch-16 B2、2m规则、R2-10k比较。

- R2B实时日志：`logs/active/g18-dense256-r2b/`；
- Gate套件实时日志：`logs/active/g18-dense256-gate-suite/`；
- 完成归档：`logs/archive/validation/g18_dense256_r2b/`和
  `logs/archive/validation/g18_dense256_gate_suite/`。

## 结果

六个当前结果数组均为`(256, 17)`，场景ID逐项等于manifest前256场，每组终止计数均为
`1280`。所有方法均在第一次尝试完成，没有并行Gazebo或sealed test读取。

| 方法 | full success | agent success | collision | unresolved | timeout | 平均步数 | I占比 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 5A | `0.2695` | `0.6992` | `0.3000` | `0.0008` | `0.0039` | `17.46` | `0` |
| R2B-best | `0.2656` | `0.6953` | `0.3031` | `0.0016` | `0.0078` | `19.80` | `0` |
| epoch17 + F-A1 | `0.4023` | `0.7758` | `0.2227` | `0.0016` | `0.0078` | `32.94` | `0.635` |
| epoch17 + F-B2 | **`0.4141`** | **`0.7844`** | **`0.2141`** | `0.0016` | `0.0078` | `40.44` | `0.716` |
| epoch17 + old B2 | **`0.4141`** | **`0.7844`** | `0.2156` | `0` | `0` | `34.30` | `0.693` |
| epoch17 + 2m真值规则 | `0.5078` | `0.8336` | `0.1594` | `0.0070` | `0.0156` | `40.12` | `0.712` |

F-A1相对5A为51场改善、17场退化、188场持平，McNemar exact
`p=4.45e-5`；相对R2B-best为51场改善、16场退化，`p=2.17e-5`。因此可部署Gate在
dense256压力集上的收益成立：相对5A的full success提高`0.1328`，collision下降
`0.0773`。代价是平均步数增加`88.7%`，必须同时报告。

F-B2相对F-A1为37场改善、34场退化，`p=0.8126`；full success仅提高`0.0117`，平均
步数却增加`22.8%`。因此继续冻结F-A1为主Gate，F-B2保留为DAgger聚合消融。old B2与
F-A1也没有显著差异（`p=0.8304`），且其训练数据包含epoch-16 student rollout，只能
作为跨Actor迁移诊断，不能替代当前方法。

2m真值规则相对F-A1为55场改善、28场退化，`p=0.00404`。这说明可部署Gate仍没有恢复
固定真值距离规则的全部收益；但2m规则依赖仿真真值，也不是严格性能上界。

F-A1在edge-1、edge-2和edge-3+均高于两个公平baseline，支持Gate收益随冲突压力保持；
0-edge只有8场，不单独作统计主张。F-B2的overall略高来自edge-2/3+，但牺牲edge-1、
0-edge和效率，四层macro反而低于F-A1。

历史同场R2-10k的full success为`0.5273`，高于当前所有可部署Gate；但它经历额外
`n1 -> n2 -> n3 -> n5`课程和不匹配预算，只作cross-protocol诊断，不能进入公平容量
baseline排序。这个结果同时说明后续不能声称双Actor结构已经超过所有单Actor训练路线。
