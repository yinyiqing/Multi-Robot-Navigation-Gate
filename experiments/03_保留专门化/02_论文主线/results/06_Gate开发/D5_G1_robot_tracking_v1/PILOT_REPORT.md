# G1 候选跟踪 Pilot

日期：2026-07-27

结论：自运动补偿和机器人轨迹关联有效，简单的跨帧概率平均不能完成机器人/静态障碍硬分类。G1 保留为 Gate 的连续运动特征前端，不再单独追求语义检测准入线。

## 数据

- train / validation 各 20 场，场景互不重叠；
- 使用冻结 5A 产生轨迹；
- 使用冻结 G0 epoch-19 checkpoint 产生单帧形状分数；
- v2 shard 保存本机位姿、时间戳和只用于离线审计的机器人 ID；
- sealed test 未读取。

| split | 场景 | 候选 | 正候选 | 可见机器人 | proposal recall |
| --- | ---: | ---: | ---: | ---: | ---: |
| train | 20 | 2931 | 817 | 849 | 0.9623 |
| validation | 20 | 2962 | 873 | 907 | 0.9625 |

## 单帧与简单平滑

validation：

| 方法 | precision | recall | FPR | F1 |
| --- | ---: | ---: | ---: | ---: |
| 冻结 G0 单帧 | 0.6719 | 0.9008 | 0.1910 | 0.7697 |
| G0 分数轨迹 EMA | 0.6484 | 0.9107 | 0.2145 | 0.7575 |

EMA 没有降低静态误报，予以拒绝。原因是墙段和箱体轨迹也会持续存在，时间平均不能提供目标身份。

## 运动与关联

只统计轨迹年龄至少为 2 的候选：

| validation 世界速度 | p10 | median | p90 |
| --- | ---: | ---: | ---: |
| 机器人正候选 | 0.213 m/s | 0.608 m/s | 1.026 m/s |
| 静态负候选 | 0.042 m/s | 0.220 m/s | 0.844 m/s |

运动中位数有明显区分，但静态候选存在很高的速度尾部，来源是点簇抖动和错误关联。因此不能用单一速度阈值硬判机器人。

关联审计：

- 232 条轨迹包含机器人正标签；
- 0 条轨迹混入多个机器人 ID，未发现机器人之间的 ID switch；
- 每个真实机器人身份平均产生 1.045 条轨迹，碎片化较低；
- 120 条机器人轨迹同时含正/负候选标签，进一步证明点簇拆分和候选级标签存在歧义。

## 决策

1. 不继续调单帧 CNN、EMA 或手工速度阈值。
2. G0/G1 输出候选形状分数、轨迹年龄、世界速度、相对速度、闭合速度、CPA 和 TTC，作为 Gate 连续输入。
3. G2 首先学习复现已经验证有效的训练期 oracle 执行契约：最近机器人真值距离 `<=2.0 m`。真值只生成监督标签，部署输入仍只有本机传感器。
4. G2 必须同时报告 interaction recall 和 standard/0-edge false activation；若静态墙面仍导致频繁切换，停止端到端 Gate，不读取 sealed test。
