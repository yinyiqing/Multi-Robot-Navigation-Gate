# 机器人与静态障碍区分：相关工作

## 横向比较

| 工作 | 输入与任务 | 能解决什么 | 对本项目的结论 |
| --- | --- | --- | --- |
| [DROW, RA-L 2018](https://doi.org/10.1109/LRA.2018.2835510) | 2D range scan，固定物理尺寸局部窗口，检测行人并回归中心 | 从局部激光形状识别特定目标 | 采用“候选周围固定物理窗口”，但保留本项目 VLP-16 的高度结构 |
| [DR-SPAAM, IROS 2020](https://doi.org/10.1109/IROS45743.2020.9341689) | 2D range scan，空间注意力与自回归历史 | 利用历史提升遮挡和稀疏检测 | 只有 G0 单帧不够时才引入目标级历史，不再对压缩 scan 直接加 GRU |
| [PointNet, CVPR 2017](https://doi.org/10.1109/CVPR.2017.16) | 无序点集分类/分割 | 直接学习点簇三维几何 | 作为局部 CNN 的轻量对照，而不是第一版主模型 |
| [4DMOS, RA-L 2022](https://doi.org/10.1109/LRA.2022.3183245) | 连续 3D LiDAR，稀疏 4D 卷积 | 区分移动与静止点 | 不能识别暂时停住让行的机器人，不能替代身份检测 |
| [Automatic Labeling for LiDAR MOS, RA-L 2022](https://doi.org/10.1109/LRA.2022.3166544) | 离线轨迹自动生成运动分割标签 | 降低逐点人工标注成本 | 支持“训练用 privileged label、部署只用 LiDAR”的数据原则 |
| [Fan et al., IJRR 2020](https://doi.org/10.1177/0278364920916531) | 传感器级多机器人避碰和混合控制 | 激光可直接驱动无通信导航 | 原方法把机器人与墙统一作为障碍；若 Gate 要切换交互 Actor，身份信息仍需单独补上 |

## 当前选择

第一版采用 `候选点簇 + 16 x 64 局部 range-view CNN + 中心回归`。原因很直接：旧 8 维手工形状已经证明点云覆盖够但表示不够；DROW 类局部窗口保留目标形状，同时比整帧 3D 检测器更适合当前五车、前视 180 度、小场地和实时 Gate。

时序不是默认前提。先完成单帧身份检测，再在检测目标上做匹配/Kalman tracking，并由相邻帧中心计算闭合速度和 TTC。这样时序模块处理的是“同一个机器人如何运动”，而不是重新猜整帧激光里什么在动。
