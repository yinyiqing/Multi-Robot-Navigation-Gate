# 历史诊断

本目录回答“旧路线为什么不能继续”，不提供当前训练入口。

| 目录 | 结论 |
| --- | --- |
| `01_冲突验证/` | 继续覆盖训练会破坏已有普通导航能力 |
| `02_双Actor切换/` | 旧 5A 与 5D 缺少足够互补性，简单切换无收益 |
| `03_dense专家训练/` | 完整 fine-tune、head-only 和早期 residual 没有形成合格 dense expert |

这些失败促成了当前方案：冻结 5A 普通导航 Actor，单独训练只在紧迫交互状态调用的条件 Actor，再训练可部署 Gate。当前结论见 [论文主线](../02_论文主线/README.md)。
