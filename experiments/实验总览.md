# 实验总览

当前唯一主线见[论文主线README](03_保留专门化/02_论文主线/README.md)。

## 项目目标

在无全局通信、无其他机器人真值的条件下，让五车同时具备普通导航和局部避让能力，
并检验只从单冲突学到的技能能否零样本组合处理多冲突。

## 当前方法

```text
Actor A：冻结5A
Actor B：冻结5A + epoch-16指导的单冲突Residual
Gate：冻结A/B后，使用本机感知选择Actor
```

论文主张是“从单冲突学习到多冲突组合泛化”，不是“双Actor + Gate”本身。

## 研究演进

| 阶段 | 结论 |
| --- | --- |
| `01_第一次尝试` | TD3、多车共享Policy、reward和局部Critic链路可运行 |
| `02_课程学习` | 得到普通五车模型5A/5D，但覆盖式dense训练容易退化 |
| `03_保留专门化/01_历史诊断` | standard/dense完整专家、旧Residual和多版独立Dense Actor均未通过 |
| `03_保留专门化/02_论文主线` | 保留5A，只学习单冲突Residual，并测试多冲突组合泛化 |

## 核心证据

- 5A在0-edge场景可靠：full success `0.875`。
- epoch-16局部技能在匹配协议有效：`0.421 -> 0.700`。
- 真值Gate在未见`edge>=2`上：`0.221 -> 0.470`。
- 可部署Gate在独立exact-edge-2上：`0.325 -> 0.405`，但尚未达到最终准入。
- 直接把epoch-16续训成完整Actor在200场复核中退化，已经停止。

## 当前顺序

1. 完成单冲突Residual Actor B短pilot；
2. 固定200场验证Actor B能否独立导航；
3. 冻结A/B，用0-edge和单冲突数据训练Gate；
4. 在exact-edge-2及更复杂拓扑做零样本验证；
5. 最后读取sealed test。

Actor B或Gate一旦用多冲突数据训练，就失去“零样本组合泛化”的主张资格。
