## 项目目标

在无通信、无其他机器人真值的条件下，让五车同时保留普通导航效率和局部机器人避让
能力，并评估局部技能在复杂多冲突场景中的重复调用价值。

## 当前方法

```text
普通导航Actor：冻结5A
条件避障Actor：冻结epoch-16
在线Gate：本机激光与时序状态 -> 逐机器人切换Actor
```

创新主张不能只写“双Actor + Gate”。候选论文问题是：局部交互技能能否在保持普通导航
能力的同时，通过可部署状态Gate组合处理更复杂的冲突拓扑。

## 研究演进

| 阶段 | 冻结结论 |
| --- | --- |
| 基础多车与课程学习 | 共享TD3链路可运行，形成普通导航5A/5D |
| standard/dense覆盖式微调 | 多次覆盖已有能力，关闭完整场景专家路线 |
| 条件交互训练 | epoch-16在局部oracle调用下形成稳定避让收益 |
| 独立Dense Actor | 在碰撞和保守timeout之间退化，关闭 |
| Residual与全程化 | 24维Residual和epoch-16整网续训未通过，关闭 |
| 第一版学习Gate | 方向为正但未过统计与oracle恢复准入，保留为基线 |
| 当前 | 冻结5A/epoch-16，只开发新的可部署Gate |
